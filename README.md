## Domínio próprio (quando comprar)
1. Criar arquivo `CNAME` na raiz com o domínio (ex.: `apcompressores.com.br`).
2. No registro do domínio, apontar o DNS pro GitHub Pages (4 registros A pra 185.199.108-111.153
   ou CNAME `www` → `arnaldohungria.github.io`).
3. Trocar a URL do `og:image` no `index.html`.
